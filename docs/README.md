# RelishClans Documentation

![RelishClans](assets/RelishClansBanner.png)

Official documentation for **RelishClans** — chunk claims, upgradable cores, wars, flags, bank, and GUI for Paper 1.21+.

## What is RelishClans?

RelishClans is a modern clan plugin for Paper servers:

- Chunk claiming with map, autoclaim, and optional contiguous territory
- Upgradable clan core (beacon) — tiers improve war capture defense
- Wars with core capture and protection drop
- Flags and upgrades backed by Vault economy
- Clan identity — color + icon tag, consistent across holograms, titles, chat, and GUI
- Storage: YAML, SQLite, or MySQL
- Soft-depends: Vault, WorldGuard, PlaceholderAPI, Floodgate, PacketEvents

## Free and Premium

RelishClans ships as a **free** jar with core clan gameplay. A **license key** unlocks premium features (wars, clan fly, core upgrades, advanced flags, claim logs, and more).

See [Free vs Premium](FreeVsPremium.md) and set `license-key` in `config.yml`. Purchase keys at the [M5LB Store](https://m5lb.run.place/).
